# Deepu Siva Private Limited — Public Website

This repository now separates the **public business website** from the legacy/internal application tools.

## Public website
- Home
- About
- Services
- Projects
- Industries
- Contact / Request a Quote
- FAQ
- Privacy / Terms

## Internal tools
Legacy ERP, billing, client portal, shop, director and utility pages are kept under `/internal/` so they are not part of the public customer navigation.

## Frontend
- HTML5
- CSS3
- Vanilla JavaScript ES modules where required by internal tools
- GitHub Pages compatible
- Mobile-first responsive layout

## Contact
The public quote form uses Web3Forms. WhatsApp is available as a direct contact channel.
